BEAT GRID REQUIREMENT (MANDATORY)

For every line in the user-provided lyrics:
	1.	Extract the beat grid using a 4/4 count:
1 & 2 & 3 & 4 &
	2.	Identify which beats align with:
	•	stressed syllables
	•	held notes
	•	phrase boundaries
	•	pickup notes (anacrusis)
	3.	Create a Beat Alignment Map (BAM) for each line.

Every rewritten line must match the original line’s BAM by:
	•	placing stressed syllables on the corresponding beats
	•	preserving pickups and held notes
	•	matching phrase length to the original measure count
	•	maintaining the same number of beats per line
	•	preserving the musical movement (rise/fall/hold)
